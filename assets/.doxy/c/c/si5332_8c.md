### function goto\_state 

_Switches the device state (READY/ACTIVE) and waits for confirmation._ 
```C++
static si5332_err_t goto_state (
    si5332_t * d,
    u8 state,
    u32 timeout_ms
) 
```



Writes `state` to [**REG\_USYS\_CTRL**](si5332_8c.md#define-reg_usys_ctrl) and then polls [**REG\_USYS\_STAT**](si5332_8c.md#define-reg_usys_stat) until it reports the same value, up to `timeout_ms` milliseconds (one poll per millisecond via bsp\_uDelay()).




**Parameters:**


* `d` Device handle. 
* `state` Requested state ([**USYS\_READY**](si5332_8c.md#define-usys_ready) or [**USYS\_ACTIVE**](si5332_8c.md#define-usys_active)). 
* `timeout_ms` Maximum time to wait, in milliseconds. 



**Returns:**

SI5332\_OK if `state` was reached; SI5332\_E\_NO\_INPUT if the device reports [**USYS\_NO\_INPUT**](si5332_8c.md#define-usys_no_input) instead; SI5332\_E\_TIMEOUT if the timeout expired without reaching `state`; SI5332\_E\_I2C on a HAL/bus error.

### function id\_encode 

_Encodes a fractional divider N = num/den into the 15-bit register triple._ 
```C++
static void id_encode (
    u32 num,
    u32 den,
    u16 * intg,
    u16 * res,
    u16 * den_reg
) 
```



Formula verified against the ID\_TEST reference export (no `-512` offset, as stated in the Si5332 reference manual): 
```C++
INTG = floor(128 * num / den)
RES  = (128 * num) mod den
DEN  = den
```





**Parameters:**


* `num` Divider numerator. 
* `den` Divider denominator. 
* `intg` INTG register value. 
* `res` RES register value. 
* `den_reg` DEN register value (equals `den`).
