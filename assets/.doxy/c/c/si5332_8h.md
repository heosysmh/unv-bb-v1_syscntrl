## Detailed Description


Concept:
* Almost all output registers (OUTx\_MODE, OUTx\_DIV, ID dividers, input/PLL registers, power-down bits) are only writable in READY mode. Changes are therefore collected in the driver ([**si5332\_set\_output\_format()**](si5332_8h.md#function-si5332_set_output_format) / [**si5332\_set\_output\_freq()**](si5332_8h.md#function-si5332_set_output_freq)) and applied with [**si5332\_commit()**](si5332_8h.md#function-si5332_commit) in a single READY-&gt;ACTIVE cycle. 

**Warning:**

Every commit briefly interrupts ALL outputs, including OUT6 (25 MHz).



* OUT6 (25 MHz CMOS system clock) is fixed and cannot be changed via the API.
* HSDIV0 (100 MHz) and HSDIV1 (125 MHz) are fixed; additional frequencies are generated via the two MultiSynths (ID0/ID1, fractional).

### function si5332\_set\_output\_freq 

_Schedules the output frequency (takes effect after_ [_**si5332\_commit()**_](si5332_8h.md#function-si5332_commit) _)._
```C++
si5332_err_t si5332_set_output_freq (
    si5332_t * pDev,
    si5332_out_ch_t ch,
    u32 freq_hz
) 
```



Routing: HSDIV0 (100 MHz) -&gt; HSDIV1 (125 MHz) -&gt; already used MultiSynth -&gt; free MultiSynth. On error, the pending state remains unchanged.




**Parameters:**


* `pDev` Device handle. 
* `ch` Output channel. 
* `freq_hz` Desired output frequency in Hz ([**SI5332\_FREQ\_MIN\_HZ**](si5332_8h.md#define-si5332_freq_min_hz) .. [**SI5332\_FREQ\_MAX\_HZ**](si5332_8h.md#define-si5332_freq_max_hz)). 



**Returns:**

SI5332\_OK on success, SI5332\_E\_FREQ\_UNSUPPORTED if no valid divider combination exists, SI5332\_E\_NO\_FREE\_MS if both MultiSynths are in use, other negative [**si5332\_err\_t**](si5332_8h.md#enum-si5332_err_t) codes on error.
