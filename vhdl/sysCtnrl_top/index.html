    Entity: sysCntrl_Top

    • File: sysCtnrl_top.vhd
    • Brief: System controller top level for the UNV baseboard (sysCntrl).

    Diagram

    Description

    Instantiates the Sapphire SoC MCU and the board-level power sequencing and supervision logic. All asynchronous board inputs are synchronized (inputSync) and, where required, debounced before use. The design controls the system / PL / PS / SYZYGY / FMC power rails, overrides open-drain power-good lines while a rail is off (to avoid false power-good indications), selects the HPC / HDB VCCIO rails via break-before-make switches (vccioSelect), and generates the PS power-on-reset and Ethernet PHY reset. MCU GPIO bank 1 carries the control outputs, GPIO bank 0 reads back the synchronized status inputs.
