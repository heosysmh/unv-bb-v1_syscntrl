    File List

    Here is a list of all files with brief descriptions:

    • dir sw
      • dir app
        • dir src
          • file boardConfig.h Single configuration point of the system controller application. Set your FMC voltages and clock config here.
          • file boardGpio.c Implementation of GPIO access (interface to FPGA).
          • file boardGpio.h Implementation of GPIO access (interface to FPGA).
          • file clkGen.c Implementation of the clock generator function group (SI5332).
          • file clkGen.h Clock generator function group (si5332).
          • file i2cBus.c Implementation of the I2C infrastructure ownership.
          • file i2cBus.h Ownership of the I2C infrastructure of the board.
          • file interrupt.c Implementation of the PLIC interrupt controller abstraction.
          • file interrupt.h PLIC-based interrupt controller abstraction for the application.
          • file main.c Board bring-up and supervision of the carrier board.
          • file power.c Implementation of the power functions.
          • file power.h Power functions of the board: FMC Vadj regulators (tpsm8286x) and the power monitors (ina745a).
          • file userDef.h Instance-pool sizes for the drivers and device drivers used by this application.
      • dir devices
        • dir ina745a
          • file ina745a.c Driver implementation for the TI INA745A/B digital power monitor.
          • file ina745a.h Driver for the Texas Instruments INA745A/B 40V, 16-Bit, Precision I2C Output Digital Power Monitor with integrated 800µΩ shunt (EZShunt).
        • dir pi4msd5v945x
          • file pi4msd5v945x.c Driver implementation for the Diodes PI4MSD5V945x I2C bus switch.
          • file pi4msd5v945x.h Driver for the Diodes PI4MSD5V945x 4-channel I2C bus switch.
        • dir si5332
          • file si5332.c Driver implementation for the Skyworks Si5332A-D-GM2 clock generator.
          • file si5332.h Driver for the Skyworks Si5332A-D-GM2 (8 outputs, 40-QFN), fixed VCO at 2.5 GHz, switchable input source (27 MHz crystal / 100 MHz CLKIN_2).
          • file si5332_cfg.c Static configuration tables.
          • file si5332_cfg.h Static configuration tables for the Si5332-GM2 Rev D (VCO 2.5 GHz).
        • dir tpsm8286x
          • file tpsm8286x.c Driver implementation for the TI TPSM8286x step-down power module.
          • file tpsm8286x.h Driver for the TI TPSM8286x step-down power module with I2C (PMBus-style) output voltage control.
      • dir drivers
        • dir i2c
          • file i2cWrapper.c Implementation of the I2C master wrapper.
          • file i2cWrapper.h I2C master wrapper around the BSP I2C driver.
