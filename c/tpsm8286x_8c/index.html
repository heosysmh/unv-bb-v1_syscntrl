    function tpsm8286_check_voltageReg

    Checks whether the VOUT1 register reads back the programmed value. 

    tpsm8286_err_t tpsm8286_check_voltageReg (
    tpsm8286_t * pDev,
    int * regOk
)

    Parameters:

    • pDev Device handle.
    • regOk Receives 1 if the register matches the last setpoint, 0 otherwise.

    Returns:

    TPSM8286_OK on success, TPSM8286_E_PARAM if pDev is NULL, TPSM8286_E_I2C on a HAL/bus error.

    tpsm8286_i2c_write_f w,

    void * ctx
)

    devId directly indexes the static instance pool (size TPSM8286_NUM_OF_INSTANCES, defined in userDef.h).

    Parameters:

    • devId Instance index.
    • i2c_addr 7-bit I2C address of the device.
    • w HAL register write callback.
    • r HAL register read callback.
    • ctx Opaque context pointer passed through to w and r.

    Returns:

    Pointer to the device handle.

    function tpsm8286_set_voltage

    Sets the output voltage setpoint (VOUT1 register). 

    tpsm8286_err_t tpsm8286_set_voltage (
    tpsm8286_t * pDev,
    float voltage
)

    The voltage is mapped to the 10 mV/LSB register scale and clamped to the supported range (0.8 V .. 3.35 V). Takes effect according to the configured ramp speed; the output enable state is not changed.

    Parameters:

    • pDev Device handle.
    • voltage Desired output voltage [V].

    Returns:

    TPSM8286_OK on success, TPSM8286_E_PARAM if pDev is NULL, TPSM8286_E_I2C on a HAL/bus error.

    function tpsm8286_voltage_to_reg

    Converts a voltage to the VOUT1 register value. 

    tpsm8286_err_t tpsm8286_voltage_to_reg (
    float voltage,
    u8 * reg_out
)

    The voltage is clamped to the range of TPSM8286_VOLTAGEMAP_10MV and mapped linearly onto the register range with rounding.

    Parameters:

    • voltage Desired output voltage [V].
    • reg_out Receives the register value.

    Returns:

    TPSM8286_OK on success, TPSM8286_E_PARAM if reg_out is NULL.
