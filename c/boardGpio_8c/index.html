    function boardGpio_getPgStatus

    Reads the power-good / ALERT nets. 

    u32 boardGpio_getPgStatus (
    void
)

    Masked to GPIO_PG_SYS_MASK, GPIO_PG_FMC1_SUP_MASK and GPIO_PG_FMC2_SUP_MASK. A bit reads 0 either because the supply is not good or because an INA745A on that net has asserted its (active low, open-drain) ALERT output.

    Returns:

    Masked power-good status bits.
