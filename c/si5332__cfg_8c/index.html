    Detailed Description

    Note:

    The CBPro export omits registers of unused blocks (e.g. 0x28 OMUX3, 0x2A OMUX5, 0x36..0x3B ID0A, 0x99 OUT4_DIV, 0xAD OUT7_DIV). These registers are written completely by the driver when a block is activated (see si5332_commit()).
