    variable gChDesc

    Static channel descriptor table. 

    const ch_desc_t gChDesc[4];

    Index order matches ch_index(): OUT0, OUT2, OUT4, OUT7.

    variable gDevice

    Single static device instance backing si5332_initialize() .

    struct si5332_t gDevice;

    variable gIdBase

    Base register addresses of the ID0A / ID1A divider triples. 

    const u8 gIdBase[2];

    For index i, INTG is at gIdBase [i], RES at gIdBase [i] + 2 and DEN at gIdBase [i] + 4; each value is 15 bit, big-endian.

    function si5332_set_output_freq

    Schedules the output frequency (takes effect after si5332_commit() ).

    si5332_err_t si5332_set_output_freq (
    si5332_t * pDev,
    si5332_out_ch_t ch,
    u32 freq_hz
)

    Routing: HSDIV0 (100 MHz) -> HSDIV1 (125 MHz) -> already used MultiSynth -> free MultiSynth. On error, the pending state remains unchanged.

    • ch Output channel.

    function id_encode

    Encodes a fractional divider N = num/den into the 15-bit register triple. 

    static void id_encode (
    u32 num,
    u32 den,
    u16 * intg,
    u16 * res,
    u16 * den_reg
)

    Formula verified against the ID_TEST reference export (no -512 offset, as stated in the Si5332 reference manual): 

    INTG = floor(128 * num / den)
RES  = (128 * num) mod den
DEN  = den

    Parameters:

    • num Divider numerator.
    • den Divider denominator.
    • intg INTG register value.
    • res RES register value.
    • den_reg DEN register value (equals den).

    function plan_id

    Plans a fresh (currently unused) MultiSynth divider for frequency f .

    static si5332_err_t plan_id (
    u32 f,
    u32 * num,
    u32 * den,
    u8 * r
)

    Selects the smallest R divider for which the resulting N = VCO_HZ / (f*R) fits into the 15-bit fractional divider (# ID_N_MIN <= N < 256), then approximates N with rational_approx() using a denominator up to ID_DEN_MAX.

    Parameters:

    • f Desired output frequency in Hz.
    • num Numerator of the resulting divider N = num/den.
    • den Denominator of the resulting divider N = num/den.
    • r Resulting R divider (1..63).

    Returns:

    SI5332_OK on success, SI5332_E_FREQ_UNSUPPORTED if no valid (R, N) combination exists for f.

    function rational_approx

    Computes the best rational approximation of n/d with a bounded denominator. 

    static void rational_approx (
    u64 n,
    u64 d,
    u32 max_den,
    u32 * out_n,
    u32 * out_d
)

    Uses a continued-fraction expansion with semiconvergents. If n/d is exactly representable with a denominator <= max_den, the reduced fraction is returned.

    Parameters:

    • n Numerator of the target ratio.
    • d Denominator of the target ratio.
    • max_den Maximum allowed denominator of the result.
    • out_n Numerator of the approximation.
    • out_d Denominator of the approximation (1 <= out_d <= max_den).

    function try_share_id

    Checks whether an already-used MultiSynth can also deliver frequency f .

    static int try_share_id (
    const id_state_t * id,
    u32 f,
    u8 * r
)

    Two outputs can share one ID divider as long as f_id / f is an integer R divider within 1..63, where f_id = VCO_HZ * id->den / id->num.

    Parameters:

    • id Shadow state of the candidate MultiSynth (must have refcnt > 0).
    • f Desired output frequency in Hz.
    • r Resulting R divider (1..63) on success.

    Returns:

    Non-zero if id can serve f, zero otherwise (r is left unchanged).

    function write_channel

    Writes (or powers down) one output channel from the shadow state. 

    static si5332_err_t write_channel (
    si5332_t * d,
    int i
)

    Always writes OUTx_MODE. If the channel is configured, writes the complete register set (OUTx_DIV, OMUX byte, power-down bits) because the CBPro export omits registers of blocks that were unused at export time. If the channel is not configured, only the OMUX and OUTx power-down bits are set to disable the block.

    Parameters:

    • d Device handle.
    • i Channel index (see ch_index()).

    Returns:

    SI5332_OK on success, SI5332_E_I2C on a HAL/bus error.

    Note:

    Must only be called while the device is in the READY state.

    function write_id

    Writes (or powers down) one MultiSynth divider from the shadow state. 

    static si5332_err_t write_id (
    si5332_t * d,
    int i
)

    If d->id[i].refcnt > 0, encodes and writes the INTG/RES/DEN register triple via id_encode() and reg_write16(), then clears the corresponding IDx_DIS bit in REG_PD_ID. Otherwise only sets the IDx_DIS bit.

    Parameters:

    • d Device handle.
    • i MultiSynth index (0 = ID0, 1 = ID1).

    Returns:

    SI5332_OK on success, SI5332_E_I2C on a HAL/bus error.

    Note:

    Must only be called while the device is in the READY state.
