    Detailed Description

    Concept: * Almost all output registers (OUTx_MODE, OUTx_DIV, ID dividers, input/PLL registers, power-down bits) are only writable in READY mode. Changes are therefore collected in the driver (si5332_set_output_format() / si5332_set_output_freq()) and applied with si5332_commit() in a single READY->ACTIVE cycle.

    Warning:

    Every commit briefly interrupts ALL outputs, including OUT6 (25 MHz).

    • OUT6 (25 MHz CMOS system clock) is fixed and cannot be changed via the API.
    • HSDIV0 (100 MHz) and HSDIV1 (125 MHz) are fixed; additional frequencies are generated via the two MultiSynths (ID0/ID1, fractional).

    function si5332_set_output_freq

    Schedules the output frequency (takes effect after si5332_commit() ).

    si5332_err_t si5332_set_output_freq (
    si5332_t * pDev,
    si5332_out_ch_t ch,
    u32 freq_hz
)

    Routing: HSDIV0 (100 MHz) -> HSDIV1 (125 MHz) -> already used MultiSynth -> free MultiSynth. On error, the pending state remains unchanged.

    Parameters:

    • pDev Device handle.
    • ch Output channel.
    • freq_hz Desired output frequency in Hz (SI5332_FREQ_MIN_HZ .. SI5332_FREQ_MAX_HZ).

    Returns:

    SI5332_OK on success, SI5332_E_FREQ_UNSUPPORTED if no valid divider combination exists, SI5332_E_NO_FREE_MS if both MultiSynths are in use, other negative si5332_err_t codes on error.
