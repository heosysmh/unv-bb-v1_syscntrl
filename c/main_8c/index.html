    Detailed Description

    : system controller application

    This file only contains the CPU-level startup (trap vector, interrupt enable) and the bring-up sequence. All device handling lives in the function groups:

    i2cBus.c I2C controllers, interrupt controller, bus switch boardGpio.c named GPIO access (enables, resets, power-good lines) power.c FMC Vadj regulators and power monitors clkGen.c clock generator

    The startup configuration is in boardConfig.h.

    function board_bringUp

    Brings the board up in the required order. 

    static int board_bringUp (
    void
)

    Ordering constraints: * The power monitors must be armed after the SoM power-good wait: their ALERT outputs are wired onto the power-good nets, so a latched alert would keep SYS_PG low and stall the wait loop. * They are armed before the FMC supply is switched on so that the FMC rails are already protected while ramping up.

    Returns:

    INIT_OK / 0 if the whole sequence succeeded, a negative error code otherwise.
