    Detailed Description

    Wraps the BSP PLIC driver (mcu/software/standalone/driver/plic.h) and the RISC-V trap handling. A single static instance manages the handler vector table; handlers are registered per interrupt ID with intr_connect() and dispatched by the machine-external trap path.
