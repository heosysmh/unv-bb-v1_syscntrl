    Detailed Description

    Bus-agnostic core driver for the INA745A/B (40V, 16-bit, precision I2C digital power monitor with integrated 800µΩ shunt). The core only uses injected HAL callbacks (ina745a_i2c_write_f / ina745a_i2c_read_f) and never includes drivers/i2c/i2cWrapper.h or any BSP header directly. Their signature matches i2c_writeRegMultipleBytes()/i2c_readRegMultipleBytes() in drivers/i2c/i2cWrapper.h, so no adapter module is needed - callers pass them in directly via a function-pointer cast (see ina745a.h).

    There is no calibration register (unlike INA226/INA228): the integrated shunt is factory-trimmed, so all LSB sizes are fixed constants (see ina745a.h and datasheet Table 8-1).

    Multiple simultaneous instances are supported analogous to tpsm8286x: ina745a_initialize() takes an explicit 'devId' that directly indexes the static instance pool (size INA745A_NUM_INSTANCES, defined in userDef.h).

    See also: ina745a.h

    See also: plans/ina745a_driver_architecture.md

    function ina745a_initialize

    Creates the device handle for instance devId (no I2C access).

    ina745a_t * ina745a_initialize (
    u32 devId,
    u8 i2c_addr,
    ina745a_i2c_write_f w,
    ina745a_i2c_read_f r,
    void * ctx
)

    Analogous to tpsm8286_initialize(): devId directly indexes the static instance pool (size INA745A_NUM_INSTANCES, defined in userDef.h), allowing multiple INA745A devices to be managed simultaneously.

    Parameters:

    • devId Instance index, 0 .. (INA745A_NUM_INSTANCES - 1).
    • i2c_addr 7-bit I2C address determined by the A0/A1 pin strapping on the board (datasheet Table 6-2), validated against INA745A_ADDR_MIN .. INA745A_ADDR_MAX.
    • w HAL register write callback, must not be NULL.
    • r HAL register read callback, must not be NULL.
    • ctx Opaque context pointer passed through to w and r.

    Returns:

    Pointer to the device handle, or NULL if devId or i2c_addr is out of range, or w/ r is NULL.
