    function i2cBus_init

    Creates the I2C infrastructure handles. 

    i2cBus_err_t i2cBus_init (
    void
)

    Creates the interrupt controller, both I2C controllers and the bus switch handle. Must be called before any device module is initialized.

    Returns:

    I2CBUS_OK on success, I2CBUS_E_INIT if a handle could not be created.

    function i2cBus_select

    Selects one or more channels of the SysCfg bus switch. 

    i2cBus_err_t i2cBus_select (
    u8 channelMask
)

    The channel mask is passed through unchanged, so several channels may be combined (e.g. I2CBUS_CH_MBRD).

    Parameters:

    • channelMask Bitmask of PI4MSD5V945X_CHx channels.

    Returns:

    I2CBUS_OK on success, I2CBUS_E_INIT if not initialized, I2CBUS_E_SELECT if the bus switch rejected the selection.

    function i2cBus_buildConfig

    Fills a controller configuration from the board definition. 

    static void i2cBus_buildConfig (
    i2cHandle_config_t * cfg,
    u32 base,
    u8 devId,
    u8 intrId,
    u8 intrPrio,
    u8 intrHart,
    u32 coreFreq,
    u32 ifFreq
)

    Parameters:

    • cfg Configuration to fill.
    • base Base address of the I2C controller.
    • devId Instance index into the wrapper's static pool.
    • intrId PLIC interrupt source ID.
    • intrPrio PLIC interrupt priority.
    • intrHart Hart (CPU) the interrupt is routed to.
    • coreFreq Controller input clock frequency [Hz].
    • ifFreq Desired I2C bus frequency [Hz].
