    Public Functions Documentation

    function pwr_checkAlerts

    Checks the power-good / ALERT lines. 

    pwr_err_t pwr_checkAlerts (
    void
)

    Only if a line is low, the devices of that group are queried over I2C; faults found are merged into the sticky fault shadow. If a line is low but no device reports a fault, the supply itself failed and PWR_E_REGULATION is returned.

    Returns:

    PWR_OK if all lines are high, PWR_E_INIT if the monitors are not configured, PWR_E_REGULATION if a line is low, PWR_E_DEVICE if a monitor query failed.

    Outputs stay disabled. The setpoints are taken from BOARD_FMC1_VADJ_V / BOARD_FMC2_VADJ_V.

    function pwr_mon_configure

    Configures and arms all monitors. 

    pwr_err_t pwr_mon_configure (
    void
)

    ADC configuration, over-voltage, over-current and over-temperature limits, latched alert, and a clearing read of DIAG_ALRT.

    Note:

    Call order matters: the ALERT outputs sit on the power-good nets, so this must run after boardGpio_waitSomReady() (a latched alert would otherwise keep SYS_PG low) and before the FMC supply is switched on.

    Returns:

    PWR_OK if all monitors were configured, PWR_E_INIT if not initialized, PWR_E_DEVICE if at least one monitor failed (the remaining monitors are still configured).

    Merges the device diagnostics into the sticky fault shadow. 

    static int pwr_mergeFaults (
    pwrRail_t rail,
    const ina745a_diag_flags_t * flags
)

    Under-voltage and under-current flags are ignored because those limits are programmed to non-trippable values (see PWR_MON_UV_DISABLED_V and PWR_MON_UI_DISABLED_A).

    Parameters:

    • rail Rail the diagnostics belong to.
    • flags Decoded DIAG_ALRT flags of the device.

    Returns:

    Non-zero if at least one fault bit was set in flags.
